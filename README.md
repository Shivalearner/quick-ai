# Quick AI — Full Stack AI SaaS Application

A fully functional AI SaaS app built with the PERN stack featuring subscription billing and 6 AI-powered tools.

## 🚀 Live Demo
[Quick AI](https://quickai-gs.vercel.app/)

## ✨ AI Features
- 📝 Article Generator
- 📰 Blog Title Generator
- 🎨 Image Generator
- 🖼️ Background Remover
- 🧹 Image Object Remover
- 📄 Resume Analyzer

## 🛠️ Tech Stack
- **Frontend** — React + Vite + Tailwind CSS v4
- **Backend** — Node.js + Express
- **Database** — PostgreSQL (Neon Serverless)
- **Auth** — Clerk
- **Deployment** — Vercel

## ⚙️ Setup
1. Clone the repo
2. Create `.env` from `.env.example`
3. Add your API keys
4. `npm install` in both client and server
5. `npm run dev`

## 📦 Environment Variables
```env
VITE_CLERK_PUBLISHABLE_KEY=
CLERK_SECRET_KEY=
DATABASE_URL=
```
